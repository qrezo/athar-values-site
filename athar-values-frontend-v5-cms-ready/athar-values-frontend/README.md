# تشغيل لوحة إدارة المحتوى

هذه النسخة جاهزة مبدئيًا لإدارة الأخبار، الصور، ملفات الحوكمة، الشركاء، وبيانات التواصل من صفحة:

`/admin/`

## طريقة التشغيل المقترحة

1. ارفع ملفات الموقع على مستودع GitHub.
2. اربط المستودع بموقع Netlify.
3. من Netlify فعّل Git Gateway.
4. افتح رابط الموقع ثم أضف `/admin/` في النهاية.
5. يدخل المدير للوحة الإدارة ويضيف الأخبار، الصور، الملفات، الشركاء، وبيانات التواصل دون تعديل الكود.

## أماكن التخزين

- الصور والملفات المرفوعة تحفظ في:
  `assets/uploads/`
- بيانات المحتوى تحفظ في:
  `data/site.json`
  `data/media.json`
  `data/governance.json`
  `data/partners.json`

## الصفحات المرتبطة تلقائيًا

- `media.html`: الأخبار، المقالات، ألبوم الصور، مكتبة الملفات.
- `governance.html`: ملفات الحوكمة والتقارير.
- `partners.html`: الشركاء.
- `contact.html`: رقم الجوال والبريد الإلكتروني.
