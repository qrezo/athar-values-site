# موقع جمعية أثر القيم — نسخة لوحة الإدارة الاحترافية

## أهم ما تغير

- استبدال لوحة Decap المعقدة بلوحة عربية مخصصة وسهلة الاستخدام.
- زر مباشر لإضافة نشاط جديد من الصفحة الرئيسية للوحة.
- بحث وتصنيف للبرامج والأنشطة عند زيادة عددها.
- إدارة بيانات الجمعية والرؤية والرسالة والأهداف من نموذج واضح.
- إدارة الجمعية العمومية ومجلس الإدارة والإدارة التنفيذية.
- إضافة الإحصاءات وتقارير الأثر.
- رفع السياسات واللوائح والقوائم والتقارير المالية.
- تعديل الجوال والواتساب والبريد ورابط Google Forms.
- دعم الجوال والكمبيوتر.
- الحفظ المباشر في GitHub من خلال Netlify Identity وGit Gateway.

## رفع النسخة إلى GitHub

ارفع **محتويات هذا المجلد مباشرة إلى جذر المستودع**، بحيث يظهر `index.html` و`admin` و`assets` و`data` في الصفحة الأولى للمستودع. لا ترفع المجلد داخل مجلد آخر، ولا ترفع ملف ZIP نفسه.

## تشغيل لوحة الإدارة

رابط اللوحة:

```text
https://رابط-الموقع/admin/
```

يلزم تفعيل التالي في Netlify:

1. Project configuration → Identity → Enable Identity.
2. Registration → Invite only.
3. Identity → Git Gateway → Enable Git Gateway.
4. دعوة بريد المسؤول من تبويب Identity.
5. بعد قبول الدعوة، يسجل المسؤول الدخول من `/admin/`.

## طريقة الاستخدام

- **إضافة نشاط:** لوحة الإدارة → إضافة نشاط جديد → اكتب العنوان والوصف وارفع الصورة → حفظ ونشر.
- **تعديل بيانات الجمعية:** بيانات الجمعية → عدّل الحقول → حفظ بيانات الجمعية.
- **إضافة عضو:** الأعضاء والقيادات → اختر القسم → إضافة عضو.
- **رفع لائحة أو تقرير:** اختر الحوكمة أو التقارير المالية → رفع ملف جديد.
- **تحديث التواصل:** التواصل والشكاوى → عدّل الرقم أو الرابط → حفظ.

بعد الحفظ ينشئ النظام تحديثًا في فرع `main`، ثم يبدأ Netlify نشر الموقع تلقائيًا. ظهور التحديث يعتمد على مدة النشر في Netlify.


## تحديث قائمة الجوال
- أصبحت القائمة الجانبية تغطي كامل المساحة المتاحة أسفل رأس الموقع على الجوال والتابلت.
- يمكن تمرير القائمة عموديًا للوصول إلى جميع التبويبات.
- تم إصلاح سبب انحصار القائمة داخل ارتفاع رأس الصفحة عند استخدام `backdrop-filter`.
- أضيف رقم إصدار لملفات CSS وJavaScript لتجاوز التخزين المؤقت بعد النشر.
