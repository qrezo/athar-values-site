# موقع جمعية أثر القيم — نسخة الإطلاق

هذه النسخة جاهزة للرفع إلى Netlify. ارفع محتويات المجلد كما هي بحيث يبقى `index.html` ومجلدا `assets` و`data` في الجذر.

## ما تتضمنه النسخة

- إصلاح قائمة الجوال واستغلال عرضها كاملًا.
- بيانات الجمعية العمومية ومجلس الإدارة والإدارة التنفيذية.
- الأهداف الاستراتيجية.
- رابط استبيان قياس رضا المستفيدين.
- جميع السياسات واللوائح والأدلة المرفقة، بروابط عرض مباشرة.
- إزالة المحتوى والأرقام والملفات التجريبية من واجهة الموقع.
- اعتماد البصمة المستخرجة من الشعار الرسمي بدل الرسم غير المطابق.

## لوحة الإدارة

بعد النشر افتح `/admin/`. يلزم تفعيل Netlify Identity وGit Gateway للحفظ المباشر.

## ملفات الحوكمة

- تتضمن النسخة 34 وثيقة من السياسات واللوائح والأدلة والآليات.
- أضيفت اللائحة الأساسية في أول قائمة اللوائح.
- تظهر شهادة الترخيص كوثيقة رسمية مستقلة إضافة إلى وثائق الحوكمة.
