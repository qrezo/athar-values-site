# موقع جمعية أثر القيم — النسخة المعاد تصميمها

تم تحديث بنية التبويبات وتصميم الواجهة وفق الهوية البصرية للجمعية.

## التبويبات المعتمدة
- الرئيسية
- عن الجمعية: شهادة الترخيص، الخريطة الاستراتيجية، الجمعية العمومية، مجلس الإدارة، الإدارة التنفيذية
- البرامج والأنشطة
- الإحصاءات والأثر
- الحوكمة
- التقارير المالية
- تواصل معنا / الشكاوى والمقترحات

## ملاحظات التشغيل
- الموقع ثابت ويمكن فتح `index.html` مباشرة أو رفع المجلد على Netlify.
- نموذج التواصل مهيأ لـ Netlify Forms.
- يمكن إضافة رابط Google Form من `data/site.json` أو لوحة الإدارة.
- ملفات السياسات والتقارير تُرفع من `/admin/` وتظهر تلقائيًا حسب التصنيف.


## لوحة الإدارة المحسنة
- رابط اللوحة: `/admin/` بعد رفع الموقع على Netlify وتفعيل Identity وGit Gateway.
- يمكن تعديل نبذة الجمعية والرؤية والرسالة والأهداف والنطاق الجغرافي.
- يمكن إضافة أعضاء الجمعية العمومية ومجلس الإدارة والإدارة التنفيذية.
- يمكن إضافة البرامج والأنشطة، والإحصاءات وتقارير الأثر.
- يمكن تحديث بيانات التواصل وربط نموذج Google Forms.
- يمكن رفع السياسات واللوائح والتقارير والقوائم المالية.

> ملاحظة: عند فتح الموقع محليًا على `127.0.0.1` تظهر واجهة لوحة الإدارة، لكن تسجيل الدخول والحفظ والنشر يحتاج رفع المشروع إلى Netlify وتفعيل Netlify Identity + Git Gateway.
