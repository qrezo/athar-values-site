# موقع جمعية أثر القيم — النسخة الاحترافية V2

## رفع الموقع

ارفع **جميع محتويات هذا المجلد** إلى جذر المستودع، بحيث توجد الملفات `index.html` و`admin` و`assets` و`data` في الجذر. لا ترفع ملف ZIP نفسه داخل الموقع.

## أهم المزايا

- هوية زرقاء وذهبية متوافقة مع شعار الجمعية.
- شعار ثانوي واضح في الكمبيوتر، وشعار أبيض وذهبي في الجوال.
- خطوط عربية احترافية وواضحة.
- صفحات مستقلة لتفاصيل البرامج والأخبار.
- عارض صور للمركز الإعلامي.
- تواصل مباشر عبر واتساب والبريد بلا نموذج أو Back-end.
- صفحة للهيكل التنظيمي والحوكمة والتقارير المالية وقياس الأثر.
- لوحة عربية لإدارة المحتوى وربط الحفظ بـ GitHub وNetlify.
- تصميم متجاوب مع شريط تواصل ثابت على الجوال.

## لوحة الإدارة

بعد النشر:

```text
https://رابط-الموقع/admin/
```

لتشغيل الحفظ المباشر يلزم تفعيل Netlify Identity وGit Gateway ودعوة بريد المسؤول. لوحة Decap الاحتياطية متاحة عبر:

```text
/admin/cms.html
```

## إضافة برنامج

لوحة الإدارة → البرامج والمبادرات → إضافة نشاط جديد.

أضف الوصف المختصر للبطاقة، ثم الشرح الكامل والأهداف والفئة المستهدفة والمدة والموقع. عند الحفظ ستظهر البطاقة في صفحة البرامج، ويفتح الضغط عليها صفحة التفاصيل تلقائيًا.

## إضافة خبر

لوحة الإدارة → الأخبار والصور → إضافة خبر.

أضف الملخص ونص الخبر الكامل والصورة والتاريخ. سيظهر الخبر في المركز الإعلامي وفي أحدث الأخبار بالصفحة الرئيسية.

## تحديث التواصل

لوحة الإدارة → بيانات التواصل.

يمكن تعديل رقم الجوال وواتساب والبريد والمدينة. لا يوجد نموذج مراسلة داخلي.

## الملفات التي تديرها اللوحة

```text
data/site.json
data/about.json
data/programs.json
data/impact.json
data/governance.json
data/media.json
data/partners.json
```

## ملاحظات قبل الإطلاق

- استبدل جميع العناصر التي تحمل كلمة «تجريبي» بالمحتوى المعتمد.
- راجع الروابط الخارجية والملفات قبل النشر.
- ارفع المجلد كاملًا حتى تظهر ملفات الشعار الجديدة وإصدار التصميم V2.
- عنوان **«مساحات تعكس الأثر»** محفوظ كما هو.

## المعاينة المحلية
يمكن فتح الصفحات مباشرة من الجهاز؛ أُضيفت بيانات تجريبية احتياطية لتظهر البرامج والأخبار والصور حتى عند منع المتصفح قراءة ملفات JSON محليًا. عند رفع الموقع إلى الاستضافة، تبقى ملفات JSON ولوحة الإدارة هي المصدر الأساسي.
